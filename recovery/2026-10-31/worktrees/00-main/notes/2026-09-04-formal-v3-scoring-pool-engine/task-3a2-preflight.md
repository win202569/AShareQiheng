# Task 3A2 preflight — not an implementation dispatch

3A1 is currently implementing the signed link contract. Do not start 3A2 before 3A1's review and commit. This document records main-agent source inspection and fixture planning, not permission to edit production code.

## Proposed split of responsibilities

- A narrow current score-feature-state adapter inside FormalFeatureRepository should reuse its closure-private dependency guard, actual provider/fact snapshots, same-root loader, unchanged V6 rebuild equality and authenticated receipt reads. It returns a new sealed candidate/pending state, never a score and never a completeness waiver from a caller boolean/key.
- Give it the genuine sealed scoring registry to resolve the registered expectation feature key. Preserve every required signed feature (including required features not used by a scoring metric), optional derived/missing status restrictions, issue/conflict checks and actual mature history. A candidate requiring consensus is not eligible by itself.
- FormalScoreInputRepository builds its own complete all-universe/all-25-slot MetricInputBatch inside an OUTER owned-provider/SQLite generation guard. No caller metric batch, score dict, confidence, year count, cyclic bool, industry string, missing-key override or arbitrary consensus object enters the proof factory.
- The complete-input factory matches every candidate's root/security/template/cutoff/feature input and bundle hash/fact and issue snapshots/provider generation to the batch feature marker. It computes metric percentiles through genuine batch/context APIs. It must not impose company history or pool eligibility on peers.
- A linked consensus request is resolved/read from the exact same Context repository using the signed descriptor scope and exact security. Group same scopes with get_verified_many to avoid a whole-table scan per member. Missing is explicit pending; corruption, equal-leading-version conflict and provenance errors propagate, not string-classified as absence.
- Verify descriptor_id and same-root/time identity in actual selected Context evidence; true no_coverage plus no_valid_coverage and empty estimates is the only neutral branch. It is a fixed SUBSCORE, separate from MetricScore. All other metric percentiles, including N >= 20, remain mandatory.
- Prepare canonical immutable result objects outside the final writer fence; publish with constant-work finalizer. Every ready input, batch and derived proof must inherit one revocable publication capability, including rollback/context-exit failures. Keep weak ownership, no cache/proof lifetime cycle.
- Readiness and pending reasons belong in the all-universe batch; a formal ready input should exist only after every gate. No arithmetic/card/pool/state migration is in 3A2.
